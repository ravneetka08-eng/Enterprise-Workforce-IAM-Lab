# INC001 Provisioning failure exercise

**Status: prepared incident worksheet. No failure has been observed yet.**

## Planned scenario

Use a deliberately incorrect SCIM token in the automation terminal while leaving the portal's correct token unchanged. The pipeline may update IdP state before receiving HTTP 401 from the target. Keep the exercise within synthetic identities.

## Investigation procedure

Record affected employee and time. Compare approved HR intent, Keycloak state, target state and failed lifecycle event. Check credential mismatch before changing mappings. Do not publish bearer values or response bodies containing sensitive information.

## Recovery procedure

Restore the correct local SCIM token in the automation terminal. Inspect any partial writes, rerun the same approved snapshot and verify both systems plus browser access before closure.
