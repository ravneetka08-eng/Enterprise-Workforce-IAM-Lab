# Service objectives

These are planned local operating objectives. They are not measured corporate SLAs.

| Process | Intended outcome | How to verify |
|---|---|---|
| Joiner | Access prepared from an approved record before simulated start | Compare source to actual groups and browser tests |
| Mover | New access added and obsolete access removed in the same reconciliation run | Both systems read back plus old/new resource tests |
| Urgent leaver | Act immediately on an authorized lab trigger | Record trigger and completed deny tests in UTC |
| Failed reconciliation | Stop and investigate before marking complete | Failure event, incident record and successful recovery |
| Temporary access | No use after expiry or revocation | Runtime denial and corresponding audit entry |
| Access review | Every finding has a decision, owner and verified remediation or open action | Before/after report and evidence index |

Corporate targets must account for business risk, staffed coverage, contracts, HR notification timing and actual platform capabilities. Record actual elapsed times when you perform the lab; do not invent service performance.
