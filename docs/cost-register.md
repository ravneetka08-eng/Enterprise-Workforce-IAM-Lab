# Cost register

**Design budget: no paid services required for the core. Actual account costs have not been inspected.**

| Component | Design decision | Verification required |
|---|---|---|
| Keycloak | Local open-source software | Record installed version |
| Portal and automation | Local Python | Record dependency installation |
| Docker Desktop | Personal education use | Check applicable licence terms |
| AWS | IAM policy and simulator only | Record private billing/plan review |
| Okta | Optional Integrator Free Plan only | Check signup and feature eligibility |
| Commercial SaaS and OIG | Excluded from the core | Do not activate a paid trial to continue |

The core does not require EC2, S3 hosting, Lambda, public IPv4, paid log storage or a purchased domain. AWS Organizations is not enabled by this project. A Free Tier eligibility label is not a universal guarantee of no charges.
