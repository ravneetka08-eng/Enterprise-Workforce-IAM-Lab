# Start here

This package is the complete starter repository for the Workforce IAM Industry Skills Manual. The planned documentation and procedures are already written. You only need to perform the lab, record actual outcomes and add sanitized evidence.

## First actions

1. Extract the ZIP using Windows **Extract All**.
2. Open the contained **iam-lab** folder in VS Code. Do not open its parent as the command working directory.
3. Open [the manual](IAM-Industry-Lab-Manual.docx), or [the browser version](docs/manual.html).
4. Follow Steps 0–4 first. When the manual says to create a document, open the existing matching file in this package and review it instead.
5. Use [progress](docs/progress.md) and [test results](templates/test-results.csv) to record what you actually complete.
6. Follow [GitHub publishing](docs/github-publishing.md) when you want to upload your work.

## Only these values need your input

- Private secrets and administrator passwords belong in local terminal variables or a password manager, never in the repository.
- Enter your GitHub username/repository URL when adding a remote.
- Enter actual dates, observed tool versions, approvals performed as a role-play, test results and evidence references as you complete the practical work.
- For temporary access, set the future expiry timestamp immediately before testing.

The provided documents describe planned design and procedures. They do not claim you have completed the implementation or operated a production organization. The complete code and artificial employee inputs are included; no earlier ZIP is required.
